# Подборка дистанционных курсов по ИТ и программированию

**Задание:** подобрать **не менее 10** курсов на открытых платформах массовых онлайн-курсов (Coursera, Интуит, Stepik, Open Education и др.).

| № | Название (тема) | URL | Примечание (кратко о программе курса) |
|---|-----------------|-----|--------------------------------------|
| 1 | **«Поколение Python»: курс для начинающих** (Stepik) | https://stepik.org/course/58852 | Бесплатно: типы данных, ветвления, циклы, строки, списки; 8 модулей, 500+ задач с автопроверкой; для школьников, студентов и взрослых. |
| 2 | **Основы программирования** (НОУ «Интуит», МГУ) | https://intuit.ru/studies/courses/2193/67/info | Алгоритм, исполнитель, типы данных, управляющие конструкции, структуры данных и поиск; дистанционно, базовый уровень. |
| 3 | **Прикладное программирование на языке Python** (Открытое образование, УрФУ) | https://openedu.ru/course/urfu/PYAP/ | Python, функциональная и объектно-ориентированная парадигмы; видеолекции, проекты, тесты; вузовский формат с сессиями. |
| 4 | **Программирование и алгоритмизация на Javascript. Часть 1** (Открытое образование, СПбПУ) | https://openedu.ru/course/spbstu/PAJS/ | Основы JavaScript для веб и прикладных задач; видеолекции, тесты и практика; возможен платный сертификат с идентификацией. |
| 5 | **Machine Learning** (Stanford, Coursera) | https://www.coursera.org/learn/machine-learning | Классический вводный курс: линейная регрессия, нейросети, SVM, кластеризация и др.; на английском, субтитры. |
| 6 | **Programming for Everybody (Getting Started with Python)** (Michigan, Coursera) | https://www.coursera.org/learn/python | Первая часть специализации Python for Everybody: установка, переменные, условия, функции; можно бесплатно слушать (аудит). |
| 7 | **CS50's Introduction to Computer Science** (Harvard, edX) | https://www.edx.org/learn/computer-science/harvard-university-cs50-s-introduction-to-computer-science | Вводный CS: C, Python, SQL, веб; задачи и проекты; один из самых известных вводных курсов в мире. |
| 8 | **Algorithms, Part I** (Princeton, Coursera) | https://www.coursera.org/learn/algorithms-part1 | Структуры данных, сортировки, графы, базовые алгоритмы; акцент на Java (по описанию курса на платформе). |
| 9 | **Спортивное программирование** (Открытое образование, СПбГУ) | https://openedu.ru/course/spbu/SPORTPROGRAMMING/ | Задачи олимпиадного уровня, C++/C#, видеолекции; часть материалов по модели платформы может быть платной. |
| 10 | **HTML, CSS, and Javascript for Web Developers** (Johns Hopkins, Coursera) | https://www.coursera.org/learn/html-css-javascript-for-web-developers | Вёрстка и клиентский JS для веб-разработки; практические задания; на английском. |
| 11 | **Программирование и знакомство с алгоритмами** (НОУ «Интуит») | https://intuit.ru/studies/professional_skill_improvements/1879/info | Стиль кода, сложность алгоритмов, поиск, сортировки, рекурсия, графы; ориентир на школьников и начинающих. |
| 12 | **Introduction to Python** (Stepik, JetBrains) | https://stepik.org/course/238 | Вводный Python для новичков; исторически связан с линейкой JetBrains Academy / EduTools. |
