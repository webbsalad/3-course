# Лабораторная работа 8  
## Тест «Компетентность во времени»

Источник методики: файл `Тест Компетентность во времени.docx`.

**Компетентность во времени** — это умение соотносить и согласовывать своё персональное время со временем других людей, работы, организации и т.п. Без выделения атрибутов и свойств времени невозможна сама идея времени.

Тест оценивает сформированность основных навыков **управления временем** и **компетентность во времени** в целом. На каждый вопрос — один из ответов: **«Да»**, **«Иногда»**, **«Нет»**.

**Баллы:** за «Да» — **2**, за «Иногда» — **1**, за «Нет» — **0**. Максимум по 25 вопросам — **50** баллов.

### Интерпретация (по методике из файла)

| Диапазон баллов | Интерпретация |
|-----------------|---------------|
| 40–50 | Высокая личностная компетентность в управлении временем |
| 29–39 | Средняя (нормальная) компетентность в управлении временем |
| 18–28 | Низкая компетентность в управлении временем |
| менее 17 | Недостаточная компетентность; время, скорее всего, используется неэффективно |

**Вывод по результату 33 балла:** **средняя (нормальная) компетентность** в управлении временем. Есть устойчивые привычки (резерв времени, записи, планирование перед работой, инструменты учёта задач, приоритизация), при этом **делегирование** и **ежедневный разбор дня** пока слабее; **долгосрочные цели** и **карьерный горизонт** прорабатываются не всегда системно.

### Краткие ориентиры по развитию (по низшим ответам)

- Ввести **короткий вечерний ретро** (5–10 минут): что съело время, что ускорило следующий день.  
- Тренировать **делегирование** в учёбе/проектах: мелкие задачи напарнику с чек-листом приёмки.  
- Формализовать **долгосрочную цель** на семестр/год в одном документе с датами контрольных точек.
